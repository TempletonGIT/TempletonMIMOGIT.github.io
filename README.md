## Overall Reflection on Agile Project Management

Working with the PRP Agile board helped me understand how a visual project-management tool can be used to organise tasks, review backlog items, and divide project work into sprints.

I learned that project planning is not only about listing activities. It is also about making work visible, understanding what needs attention, and maintaining useful records of progress. The board screenshots provide supporting evidence of the planning information available to me.

This assessment also highlighted the importance of keeping project documents organised. A Trello board, an Agile Team Charter, and an Agile Logbook serve different purposes. The board helps visualise tasks and planned work, the charter establishes shared expectations, and the logbook records progress and learning over time.
